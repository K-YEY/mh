## Free and Premium Shadcn UI Components for Modern Apps

A growing collection of beautifully designed, clean and modern [shadcn/ui](https://ui.shadcn.com) components built for [React](https://react.dev) and [Next.js](https://nextjs.org) projects. Browse 500+ free and premium component variants in 48 categories. Each component focuses on behavior, interaction and reuse, helping teams build consistent interfaces, scalable design systems and production ready applications faster. Start with the free components or unlock the whole collection with [All Access](https://shadcnuikit.com/pricing).

### Why Developers Choose These Shadcn UI Components
- Preview, copy or install: Preview every variant live, copy the code with one click or install it directly through the shadcn CLI and our registry.
- Easy to customize: Modify layout, styles and behavior directly in code with [Tailwind CSS](https://tailwindcss.com) utilities and CSS variables, without breaking structure.
- [Radix UI](https://www.radix-ui.com) and [Base UI](https://base-ui.com) support: Every component works with both Radix UI and Base UI primitives, so you can use the library that fits your stack.
- 48 component categories: From [accordions](https://shadcnuikit.com/components/accordion) and [buttons](https://shadcnuikit.com/components/button) to [data tables](https://shadcnuikit.com/components/data-table) and [tooltips](https://shadcnuikit.com/components/tooltip), every category is organized for quick discovery.
- Variants and states included: Hover, active, disabled and loading states are covered, so components behave correctly in production from day one.
- Dark mode ready: Every component supports light and dark themes out of the box. Create your own palette with the free [Theme Generator](https://shadcnuikit.com/theme-generator).
- Works across React frameworks: Fully compatible with Next.js and modern React setups used in SaaS products, admin dashboards and landing pages.
- CLI and MCP integration: Browse, generate and extend components directly inside your development environment with the shadcn CLI and MCP server.
